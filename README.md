## Simple BMI Calculator

A simple BMI calculator that checks whether the user's weight is underweight, normal, or overweight based on height and weight.
[live link](https://shivani-jaiswal88.github.io/simple-bmi-calculator-project-js/)

## Features

1. Enter your height and weight
2. Click the Calculate button
3. Check your BMI result

# Technologies Used

1. HTML5
2. CSS
3. JAVASCRIPT
